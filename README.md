# Planet 安装包发布仓库

这里只放 Planet 桌面端的**安装包与自动更新元数据**（Planet-Setup-*.exe / .blockmap / latest.yml），
供已购买的用户下载与自动更新使用。应用源码不在本仓库。

## 下载

见 [Releases](https://github.com/daoiu/planet-releases/releases) 页：下载最新的 `Planet-Setup-x.y.z.exe`，
双击安装即可（按用户安装，不需要管理员）。首次启动需要输入购买时收到的激活码。

## 升级

从 v1.1.1 起，应用会在启动后自动检查更新并在退出时安装，无需手动下载。
早于 v1.1.1 的安装内置的是旧更新源，需要手动下载安装包覆盖安装一次。
